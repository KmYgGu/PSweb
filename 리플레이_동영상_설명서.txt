==============================================
 리플레이 / 동영상 저장 / 그림 교체 설명서
==============================================

[1] 리플레이 보기
- 전투가 끝나면 결과 화면에 버튼 2개가 나옵니다.
  ▶ 리플레이      : 경기 전체를 처음부터 봅니다.
  ★ 최고의 플레이 : 하이라이트 장면을 배너와 함께 봅니다.
- 리플레이는 "마지막 경기 1개"만 남습니다. 남기고 싶으면 꼭 저장하세요.

[2] 리플레이 화면 조작
- 하단 타임라인 끌기 : 원하는 장면으로 되감기/빨리감기
- ⏮ : 처음으로
- ▶ / ❚❚ : 재생 / 일시정지
- 0.5x / 1x / 2x : 재생 속도
- ★ : 누를 때마다 하이라이트 1위 → 2위 → 3위
- A / B : 원하는 구간의 시작(A)과 끝(B) 찍기
- ✕ : 결과 화면으로 돌아가기
- 타임라인의 노란 띠 = 하이라이트, 하늘색 점선 = A~B 구간

[3] 리플레이 파일 저장 (.psreplay, 아주 작음 1KB 정도)
- 리플레이 화면에서 [저장] → 하이라이트 / A~B 구간 / 전체 경기 중 선택
- 다시 볼 때 : 캐릭터 선택 화면 하단 [📂 리플레이 열기] → 파일 선택
- 주의 : 게임 코드를 고친 뒤에는 예전 리플레이가 다르게 재생될 수 있습니다.
         이때 화면에 "다른 버전에서 저장됨" 또는 "⚠ 재현 불일치"가 뜹니다.

[4] 동영상 저장 (.webm)
- 리플레이 화면에서 [저장] → "🎬 동영상 저장" 아래에서
  ★ 하이라이트 / A~B / 전체 중 선택
- 실제 길이만큼 녹화 시간이 걸립니다. (8초 하이라이트 ≒ 11초, 42초 경기 ≒ 43초)
- 녹화 중 하단에 빨간 진행 막대와 [취소] 버튼이 나옵니다.
- 녹화하는 동안 브라우저 탭을 다른 창으로 가리거나 내리지 마세요(느려집니다).
- 결과 : 720x1280, 30fps, 소리 없음. 크기는 하이라이트 약 3.5MB, 전체 약 15MB.
- 상단 UI, 로그, 배너까지 들어가고, 리플레이 조작 버튼은 안 들어갑니다.

[5] ★ 그림(PNG) 바꿨을 때 꼭 할 일 ★
- 게임 화면 : assets 폴더의 PNG를 같은 이름으로 덮어쓰면 바로 바뀝니다.
- 동영상에도 새 그림이 나오게 하려면 :
    1) tools\에셋갱신.bat 을 더블클릭
    2) 게임 창에서 F5 (새로고침)
- 깜빡했을 때 : 녹화 전에 바뀐 그림을 찾아 알려줍니다.
    [📁 assets 폴더 선택] → 이번 녹화에 새 그림을 바로 사용
    [그대로 녹화]        → 예전 그림으로 녹화
    [취소]              → 녹화 취소
- 주의 : 가로세로 크기가 "똑같은" 그림으로 바꾸면 자동으로 못 찾습니다.
         이때는 꼭 에셋갱신.bat 을 실행하거나,
         저장 메뉴의 [📁 assets 폴더에서 읽기]를 누르세요.

[6] 그림 파일 위치 (구울즈)
- assets\Ghouls\character\front.png / back.png / portrait.png
- assets\Ghouls\monsters\G01.png ~ G40.png (카드 번호 순서)

[7] 알려진 차이
- 동영상의 화면 흔들림이 실제 화면과 조금 다릅니다.
- 동영상의 상단 UI 글자 그림자는 빠져 있습니다.
- mp4가 아니라 webm으로 저장됩니다.
