# 시각 효과 복구본

이 폴더는 이 대화에서 2026-10-21에 작업한 마지막 버전입니다.
Git 기준 커밋 `9f0ac07` 위에 이 대화의 실제 수정 기록을 순서대로 적용해 복원했습니다.
현재 프로젝트의 작업 파일은 덮어쓰지 않았습니다.

## 전달할 파일

- `game.js`: 타격 문양, 스프라이트 피격 변형, K.O. 배경 암전과 타이틀, 공격 예고, 충격파, 돌진 잔상·벽 파편, 무기·투사체 디테일, 마지막 오버워치 참고 화염 강타.
- `main.js`: 화면 시간에 맞춰 `battle.updateVisual(dt)`를 호출하는 연결부.
- `skills.js`: 라인하르트 돌진 준비 표시와 화염 강타 발사 효과.
- `broly.js`: 기탄의 에너지 꼬리와 회전층.
- `project-README.md`: 당시 프로젝트 문서.
- `visual-effects.patch`: 기준 커밋 대비 전체 변경 내역. 병합 참고용입니다.
- `manifest.json`: 파일별 복원 기록 수와 SHA-256 해시.

## 현재 작업과 합칠 때

이 파일들은 당시 완성본이며, 그 이후 추가된 갈포드 등 현재 프로젝트의 새 변경은 포함하지 않습니다.
현재 파일을 통째로 교체하기보다는 `visual-effects.patch`와 복구본을 참고해 필요한 부분을 병합하세요.
`game.js`의 새 효과는 `main.js`의 `updateVisual(dt)` 호출과 함께 사용해야 합니다.
